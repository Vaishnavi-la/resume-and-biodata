M S Vaishnavi – Resume & Bio-data Website
A multi-page student resume and bio-data website created using HTML, CSS and JavaScript.
Pages
`index.html` – Home
`resume.html` – Resume
`biodata.html` – Bio-data
`skills.html` – Skills
`contact.html` – Contact
Folder Structure
```text
MS_Vaishnavi_Resume_Biodata_Website/
│
├── index.html
├── resume.html
├── biodata.html
├── skills.html
├── contact.html
├── README.md
│
├── css/
│   └── style.css
│
└── js/
    └── script.js
```
Run on your computer
Simply double-click `index.html`, or open it with a browser.
Host on GitHub Pages
Create a GitHub account if you don't already have one.
Create a new public repository, for example:
`vaishnavi-resume-website`
Upload all files and folders from this project.
Go to Settings → Pages.
Under Build and deployment, select Deploy from a branch.
Select the `main` branch and `/ (root)`.
Save.
GitHub will provide your public website URL.
Important
The contact form in this student project is a front-end demonstration. It does not send email to a server.
