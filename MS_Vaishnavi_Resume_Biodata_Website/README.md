# M S Vaishnavi – Resume & Bio-data Website

A multi-page student resume and bio-data website created using HTML, CSS and JavaScript.

## Pages
- `index.html` – Home
- `resume.html` – Resume
- `biodata.html` – Bio-data
- `skills.html` – Skills
- `contact.html` – Contact

## Run on your computer
Simply double-click `index.html`, or open it with a browser.

## Host on GitHub Pages
1. Create a GitHub account if you don't already have one.
2. Create a new public repository, for example:
   `vaishnavi-resume-website`
3. Upload all files and folders from this project.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`.
7. Save.
8. GitHub will provide your public website URL.

## Important
The contact form in this student project is a front-end demonstration. It does not send email to a server.
